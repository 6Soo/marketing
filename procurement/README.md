# 숲길여행 나라장터 신청 준비

현재 명세: `NARA-20261020`, 버전 3. 최신 사용자 확인에 따라 **등기임원 개인회원 계정으로 나라장터 회사 신규 등록부터 완료**합니다. 실제 보유분은 현재 PC의 은행보험용 공동인증서뿐이며 나라장터에서 허용되지 않습니다. 사용자가 KB국민은행 기업금융인증서 1년·4,400원 발급을 승인했습니다. 실제 발급과 사용자 본인확인을 기다립니다. 특정 공고 응찰은 현재 실행 범위에서 제외합니다. **실제 회사 등록은 아직 완료되지 않았습니다.**

현재 관광사업등록증·사업자등록증·등기부와 본점 이전 자료를 확인했습니다. 본점은 강서구이며, 회사 전화는 `02-6091-0977`, 업무 이메일은 `aslan@foresttour.kr`입니다. [현재 확인 시점 사본](evidence/company-current.json)의 정본은 foresttour `docs/회사서류/현재-회사정보.json`입니다. 등기부의 동·건물명은 다른 두 등록증과 다르고, 사용자는 아직 정정하지 않았다고 확인했습니다.

원본 폴더 17개 파일은 모두 비공개 로컬 보관함으로 복사하고 해시를 대조했습니다. 개인정보와 사적 대화가 있어 전체 원본을 Git에 올리지는 않습니다. 전체 식별 목록과 안전한 회사정보, 개인정보가 없는 참고 빈서식은 foresttour 회사서류 보관함에 반영합니다. 이 구분을 원본 17개 업로드 완료로 표현하지 않습니다.

## 판단 기준

서울 본점과 국내외여행업 1262를 출발점으로 삼습니다. 실제 관광사업등록증과 최신 등기가 우선입니다. 종합여행업·행사대행업·제조품목·직접생산을 임의로 추가하지 않습니다. 대구지점이 본점 지역제한을 해결한다고 가정하지 않습니다.

학교 여행은 기존 성인 카페 여행과 항공·안전·정산 조건이 다릅니다. 회사의 기존 운영 방식을 발주 조건에 자동 적용하지 않습니다. 원가와 회사 귀속 이익, 최대 선지출, 취소 노출액을 확인한 공고만 다음 단계로 넘깁니다.

개인정보가 담긴 증명서와 고객 실적 원본은 이 폴더에 넣지 않습니다. 작업용 양식에는 고객 이름·연락처·여권·주민번호를 쓰지 않습니다. 원본 수집은 회사의 승인된 보안 보관 경로를 사용합니다.
