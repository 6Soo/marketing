## 판단 기준

서울 본점과 국내외여행업 1262를 출발점으로 삼습니다. 실제 관광사업등록증과 최신 등기가 우선입니다. 종합여행업·행사대행업·제조품목·직접생산을 임의로 추가하지 않습니다. 대구지점이 본점 지역제한을 해결한다고 가정하지 않습니다.

학교 여행은 기존 성인 카페 여행과 항공·안전·정산 조건이 다릅니다. 회사의 기존 운영 방식을 발주 조건에 자동 적용하지 않습니다. 원가와 회사 귀속 이익, 최대 선지출, 취소 노출액을 확인한 공고만 다음 단계로 넘깁니다.

개인정보가 담긴 증명서와 고객 실적 원본은 이 폴더에 넣지 않습니다. 작업용 양식에는 고객 이름·연락처·여권·주민번호를 쓰지 않습니다. 원본 수집은 회사의 승인된 보안 보관 경로를 사용합니다.
