# 나라장터 로컬 인증서 미표시 점검

확인일: 2026-10-20. 회사 등록 신청서는 임시저장 상태이며 실제 송신·접수·승인은 아직 확인되지 않았습니다.

## 확인 결과

현재 표준 로컬 폴더에서 찾은 숲길여행 명의 인증서는 금융결제원의 사업자 은행·보험용 인증서입니다. 용도 코드가 `1.2.410.200005.1.1.2`이며, 실제 나라장터의 법인 인증서 허용 목록에는 이 코드가 제외되어 있습니다. 인증서 파일을 찾지 못하는 현상의 핵심 원인은 확인한 인증서의 용도 제한입니다. 다른 위치에 보유한 범용 인증서가 없다고 단정하지 않습니다.

| 점검 | 실제 근거 |
|---|---|
| 표준 로컬 폴더 | 사용자 프로필의 `AppData/LocalLow/NPKI`에서 공개 인증서 한 개와 짝이 되는 키 파일 존재 확인 |
| 회사명 일치 | 공개 인증서의 회사명 일치 여부만 확인. 개인 이름·식별번호·일련번호·전체 인증서 내용은 기록하지 않음 |
| 유효기간 | 확인한 공개 인증서는 점검 시점에 기간 내 유효. 폐지 여부·비밀번호·실제 서명은 미확인 |
| 용도 코드 | `1.2.410.200005.1.1.2`. 나라장터 공식 스크립트에서 사업자 은행보험용으로 표시 |
| 허용 목록 대조 | 주석을 제외한 `PKI_CERT_POID_COMPANY`의 50개 용도 코드에 위 은행용 코드 없음. 금융결제원 범용 법인 코드 `1.2.410.200005.1.1.5`와 사업자 금융인증서 코드 있음 |
| MagicLine | 설치 버전 `1.0.0.33`, 본체와 서비스 프로세스 실행 중. 실제 나라장터 설정의 Windows 요구 버전도 `1.0.0.33` |
| 로컬 연동 | Aside의 하드디스크 선택에서 C·D·이동식 드라이브 목록이 나옴. C드라이브 선택 후 허용 인증서 목록은 비어 있음 |
| 추가 위치 | C·D 표준 NPKI 위치와 사용자 다운로드·바탕화면·문서, D드라이브 다운로드를 확인한 범위에서는 추가 후보를 찾지 못함. 전체 PC와 다른 사용자·컴퓨터를 모두 조사한 것은 아님 |

## 해결 경로와 현재 대기

기존 사업자용 범용 공동인증서가 다른 폴더·USB·다른 컴퓨터에 있으면 해당 위치에서 가져옵니다. 사용자는 저장 위치와 보유 여부만 답변하며 인증서 파일·키 파일·비밀번호를 채팅이나 Git으로 보내지 않습니다.

별도 범용 인증서가 없으면 조달청에서 허용하는 사업자용 금융인증서 보유 여부를 확인합니다. 현재 나라장터 인증서 창에도 금융(사업자)인증서 경로가 있습니다. 은행용 공동인증서와 사업자용 금융인증서는 서로 다른 인증수단입니다. 신규 발급·결제는 실행하지 않았으며 과금은 별도 사용자 결정이 필요합니다.

드림시큐리티 공식 문서가 안내하는 브라우저 가져오기는 정상 인증서를 해당 브라우저에 등록하는 방법입니다. 가져오기로 은행용 인증서의 용도가 범용으로 바뀌지는 않습니다. 적합한 인증서가 확인된 뒤 해당 방법을 사용합니다. 숨김 폴더를 찾을 때는 탐색기 주소창에 `%USERPROFILE%\AppData\LocalLow\NPKI`를 입력합니다. 공식 가져오기 화면에서는 `signCert.der`와 `signPri.key`를 함께 선택하도록 안내합니다. 비밀번호 입력·실제 전자서명은 사용자가 직접 처리합니다.

현재 사용자에게 별도 범용 인증서의 보유 여부와 저장 위치를 질문한 상태입니다. 적합 인증수단이 확보되면 저장된 신청서를 다시 불러와 송신 검증 → 회사 전자서명 → 접수내역·온라인 제출서류 확인 순서로 재개합니다.

## 공식 근거와 저장 경계

- [나라장터 공식 인증 처리 스크립트](https://www.g2b.go.kr/kn/com/js/jsPkiUtil.js?postfix=2026_10_20): 용도 구분, 법인 허용 목록, 서명 시 인증서 용도 검사 확인. 읽기만 했으며 서버·클라이언트 설정을 바꾸지 않음.
- [나라장터 공식 MagicLine 설정](https://www.g2b.go.kr/MagicLine4Web/ML4Web/js/ML4Web_Config.js?postfix=2026_10_20): Windows 요구 버전 확인.
- [조달청 등록업무 안내](https://pps.go.kr/kor/content.do?key=00170): 사업자용 범용 공동인증서와 사업자용 금융인증서 안내.
- [드림시큐리티 브라우저 인증서 안내](https://www.dreamsecurity.com/download/browsercert_guide.pdf): 설치 없이 브라우저에 가져오는 방법과 두 파일 선택 안내.

공식 공개 스크립트는 Git 제외 폴더 `evidence/raw/g2b-jsPkiUtil-2026-10-20.js`에 근거로 보관합니다. SHA-256은 `0ecceca0ddc32349bfb1eaf672dc038f6ea17745df2f97fe679fa91a593b69a9`입니다. 비밀키 파일은 읽거나 복사하거나 업로드하지 않았습니다. 인증서 비밀번호도 수집하지 않았습니다. 프로그램 재설치·보안 설정 완화·허용 목록 변경·신규 과금은 실행하지 않았습니다.
