## 최신 증빙과 주소 차이

본점 이전 결정서 DOC-12와 2026-09-29 발행 등기부 DOC-10에서 이전일 2026-09-15, 변경 등기일 2026-09-16을 확인했습니다. 마포구 주소는 이전 주소이므로 신규 신청에 복사하지 않습니다.

사업자등록증·관광사업등록증은 `등촌동, 비원오피스텔`, 등기부는 `공항동, 비엔오스텔`로 표기합니다. 사용자는 아직 정정하지 않았다고 확인했습니다. 등기부가 정정됐다고 기록하거나 서로 다른 원본을 같은 표기로 전사하지 않습니다. 이 차이의 신청 처리 방식은 등록 담당자 또는 실제 신청 화면에서 확인해야 하며, 반려나 등록 불가를 단정하지 않습니다.

회사정보의 정본은 foresttour `docs/회사서류/현재-회사정보.json`, 이 작업의 확인 시점 사본은 `evidence/company-current.json`입니다. 원본 17개는 개인정보와 사적 대화가 포함돼 Git에 넣지 않고 `C:/AX/private-company-records/foresttour/2026-10-20/originals`에 모두 복사해 SHA-256을 대조했습니다. 저장소에는 개인정보가 없는 확인 내용과 식별 목록을 반영합니다.

## 실제 화면과 등록 흐름

2026-10-20 Aside 브라우저에서 나라장터 홈 → 이용자등록, 고객센터 → 이용자 등록절차의 개인회원·조달업체 탭을 확인했습니다. 홈에는 로그인 링크가 표시됐으며 회사 인증 상태는 확인되지 않았습니다.

공식 경로는 **개인회원 등록·본인인증 → 로그인 → 이용자관리 → 조달업체등록 → 입찰참가자격등록신청 → 해당 분야·증빙 입력 → 사업자 인증서 서명·전송 → 조달청 승인**입니다. 개인회원 가입만으로 회사 등록이 끝나지 않습니다. 승인 후 등록증의 대표자·주소·업종을 확인하고 인증서·소속·대리인 연결을 마칩니다.

실제 폼을 로그인 후 열지 못했으므로 이 입력안의 항목명은 제출 화면을 완전히 복제한 명세가 아닙니다. 현행 폼에서 요구하는 값만 입력합니다. 등록 완료 판단에는 접수번호·승인 상태·등록증이 필요합니다.

근거: [조달청 등록업무안내](https://www.pps.go.kr/kor/content.do?key=00170), [나라장터 이용자 등록절차](https://www.g2b.go.kr/ehelpdesk/FCSE009_01/).

## 인증서 선택

| 경로 | 사용 범위 | 회사 적용 |
|---|---|---|
| 사업자용 범용 공동인증서 | 일반 업무 전반 | 기존 보유·유효성·사용 범위부터 확인 |
| 사업자용 금융인증서 | 전자세금계산서를 제외한 업무 | 법인도 후보. 전자세금계산서는 별도 인증 경로 필요 |
| 개인사업자용 간편인증서 | 개인사업자 대상 | 숲길여행 법인에 그대로 적용하지 않음 |
| 개인 본인인증 | 회원 로그인과 개인 식별 | 사업자 서명용 인증과 별개 |

현재 공식 안내의 연간 표시액은 범용 공동인증서 일반 110,000원, 사업자용 금융인증서 4,400원입니다. 실제 발급기관·기존 계약의 가격과 사용 범위를 다시 확인합니다. 이번 준비에서 발급·구매·결제를 하지 않았습니다. 인증서·비밀번호·인증 코드는 문서나 채팅으로 받지 않습니다.

## 증빙과 역할 구분

- 용역 등록에는 업종별 면허·허가·등록·신고 증명과 인감 관련 서류를 대조합니다. 사업자등록증·등기는 행정정보공동이용으로 확인되면 별도 제출이 생략될 수 있습니다. 모든 서류의 일괄 재발급을 전제하지 않습니다.
- 제조업의 상시근로자·공장 요건을 여행 용역에 그대로 적용하지 않습니다. 직원 0명 기록만으로 기본 등록 불가라고 판단하지 않습니다.
- 사내이사라는 기록만으로 대표자 권한을 행사하지 않습니다. 대표자 직접 경로와 입찰대리인 경로를 구분합니다. 임원 등기·재직·보험 자료의 인정 범위는 현행 규정과 등록 담당자의 안내로 확정합니다. 없는 근로관계나 보험 가입을 만들어 기재하지 않습니다.
- **기본 등록**, **소기업·소상공인 확인**, **공공입찰용 신용평가**, **공고별 실적·보험**은 서로 다른 요건입니다. 신용평가·중소기업확인이 모든 기본 등록의 선행 요건이라고 단정하지 않습니다.

근거: [조달청 구비서류 안내](https://www.pps.go.kr/kor/content.do?key=00171), [정부24 민원 안내](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=12300000001&HighCtgCD=A09001), [등록규정](https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000274756).

## 중소기업확인서 준비 기준

[중소기업현황정보시스템](https://sminfo.mss.go.kr/cm/sv/CSV001R0.do)의 **법인사업자** 흐름을 사용합니다. 2019년 설립 기록이므로 2025·2026년 신설법인 경로로 분류하지 않습니다. 근로소득 원천세 신고, 합병·분할, 관계기업 여부를 실제 세무자료로 확인한 뒤 자료제출 유형을 선택합니다. 직원이 없다는 이유로 법인 재무자료 제출까지 자동 면제된다고 가정하지 않습니다.

재무자료 제출 → 제출자료 조회 → 신청서 작성·제출 → 진행상황 → 확인서 출력 흐름을 확인했습니다. 공공기관 입찰에 사용할 용도와 기업 규모, 유효기간, 공공구매망 반영 여부를 확인합니다. 실제 공고가 소기업·소상공인만 허용하면 중기업 확인만으로는 충족되지 않습니다.
