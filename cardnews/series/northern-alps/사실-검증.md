## 계절·사진 정합성

- 01 갓파바시: 2015-09-20 촬영. 가을 후반으로 오인시키는 “10월 단풍” 표현을 붙이지 않는다.
- 02 미쿠리가이케·04 구로베댐: 2021-09-21 촬영.
- 03 다테야마 로프웨이: 2022-05-07 촬영. 사진 속 눈을 특정 게시월의 현황으로 말하지 않는다.
- 04 다이칸보: 2011-10-13 촬영. 원문 좌표·Lake Kurobe·Tateyama 범주와 촬영일을 확인했다.
- 06 아즈사가와: 2011-07-26 촬영.
- 07 히라유 폭포: 2007-11-23 촬영. 눈·고드름이 보이는 초겨울 장면이므로 카드와 랜딩에서 촬영일을 밝히고, 연결 출발일의 적설·현황으로 오인시키지 않는다.
- 08 최종 카드: 가미코치~야리가타케 산행로의 2012-10-22 단풍 사진.
- 구로베댐 관광 방류는 통상 6월 26일~10월 15일이며 날씨로 취소될 수 있다. 연결 상품 출발일과
  맞지 않으므로 이번 카드에는 방류 장면·방류 기대 문구를 쓰지 않는다.

## 예약 연결 불변식

- 연결 후보는 예약 API 상품 ID `fNod`.
- 제목에는 `알펜루트`, `가미코지`, `노리쿠라`가 모두 포함되어야 한다.
- 공개 예약 API에서 이 ID와 제목 조건이 현재 노출 가능한 상태로 확인될 때만 랜딩 CTA를 보여준다.
- API 실패·빈 결과·스키마 변경·ID 또는 제목 불일치 시 CTA를 숨긴다(fail-closed).
- 카드와 캡션에는 가격·출발일·여행일수·예약 문구를 넣지 않는다.
