## 2026-07-28 출처 기록 정정 (사진 재수급 없음)

Commons API를 다시 조회해 `*.source.json` 5건을 재생성했다. 이미지 바이트는 건드리지 않았고,
`width`/`height`/`sha256`은 로컬 파일에서 직접 실측한 값이다.

- `04-taraibune.jpg` — 기록 2400×1800 → **실측 3840×2880**으로 정정(원본 4608×3456의 Commons 썸네일).
- `05-shukunegi.jpg` — 기록 5184×3456(원본 치수) → **실측 3840×2560**으로 정정(원본 5184×3456의 Commons 썸네일).
- 5건 모두 `revisionId`/`revisionTimestamp`/`revisionUrl`/`description`/`categories`/`gps`를 추가해
  북알프스(004)와 같은 스키마로 맞췄다. 리비전 ID는 모두 Commons API 실조회 값이다.
- SHA-256은 5건 모두 기존 기록과 일치했다(정정 없음). `localSha1`을 추가해 원본/썸네일 여부를 명시했다.
  `02`·`03`·`cover-a`는 로컬 SHA-1이 Commons 원본 SHA-1과 일치(원본 바이트), `04`·`05`는 썸네일이다.
- 퍼블릭 도메인 2건은 Commons가 `LicenseUrl`을 제공하지 않아, 해당 파일에 적용된 라이선스 템플릿
  문서(`https://commons.wikimedia.org/wiki/Template:PD-user`)를 `licenseUrl`로 기록하고
  `licenseUrlNote`에 사유를 남겼다.

## 2026-07-29 표지 사진 수급 — 해소

표지가 3장 카드와 같은 `03-kitazawa.jpg`를 재사용해 검증기의 "중복 없는 2~10장" 규칙에
걸리던 문제를 해소했다.

- 새 표지: `01-kitazawa-terrace.jpg` — Commons `File:北沢浮遊選鉱場内の濁川 02.jpg`,
  저작자 Indiana jo, **CC0**, 3648×2736, 고정 리비전 993748777.
  같은 북택부유선광장이지만 3장 카드와 다른 사진이며 층층 테라스가 우측에 뚜렷하다.
- 예비 `cover-a.jpg`(1515×975)는 게시 최소 높이 1067을 넘지 못해 여전히 표지로 쓰지 않는다.
  표에는 `예비`로 남겨 둔다.
- **로컬 재인코딩 고지**: Commons 원본 바이트가 JPEG 종료 마커(FF D9) 없이 끝나 게시
  파이프라인의 JPEG 검사를 통과하지 못했다. Commons 서버도 이 파일의 썸네일 생성에 실패해
  요청 폭과 무관하게 원본을 반환한다. 그래서 픽셀 크기·크롭·색을 바꾸지 않고 JPEG로만
  재인코딩(quality 92, 4:4:4)했다. Commons 원본 SHA-1은 `commonsSha1`에 보존했고,
  로컬 바이트 해시는 `sha256`/`localSha1`에 기록했다.
- 이번 변경은 **로컬 소스 교체까지만**이다. 재렌더·재게시하지 않았으므로
  `cardnews/out/sado/`의 기존 PNG와 이미 공개된 Instagram 게시물은 옛 표지 상태 그대로다.
