# 숲길여행 유튜브 편집 SOP & 학습 루브릭

**대장 호스트 · 쇼츠 → 롱폼 깔때기** · 2026-07-19 신설
*(목적: 카페 밖 젊은 수요를 여는 별도 채널. 회원에게 파는 '변화'가 아니라, 새 수요를 여는 창구 — docs/학습-08·수요 이원 원칙과 같은 방향.)*

## 0. 채널 한 줄 전략

- **포맷**: 대장(아슬란 등)이 얼굴·목소리로 나오는 호스트 브이로그. **쇼츠로 유입 → 롱폼으로 팬화.**
- **차별점**: 무난한 목적지 화보가 아니라 **"누가 왜 가는지"가 뾰족한 대장 동행.** 학습-08의 성장엔진(호스트 + 뾰족한 테마 + 1인 참가자)과 정합.
- **금지**: 럭셔리 화보 톤(우리 데이터에서 실패). 2030은 오히려 **평범한 일상의 진정성**을 신뢰 — 과편집보다 진짜.

## 1. 깔때기 설계 (쇼츠 → 롱폼)

| 단계 | 길이 | 역할 | 연결 |
|---|---|---|---|
| 쇼츠 | 20~50초 | **발견·유입** — 롱폼의 가장 강한 순간 1개 | 설명·고정댓글에 롱폼 링크 |
| 롱폼 | 5~12분 | **팬화·신뢰·예약 동기** | 콜드오픈에 "이 여행 더 보기" |

- **업로드 리듬**: 쇼츠 주 2~3편 · 롱폼 주 1편(현실상 격주도 무방 — **꾸준함이 완벽함보다 우선**).
- 쇼츠 3~5편을 먼저 뿌려 반응 좋은 소재를 확인한 뒤, 그 소재로 롱폼을 만드는 순서가 안전합니다.

## 2. 훅 공식 (첫 3~10초가 전부)

- **쇼츠**: 0초에 절정 컷 + 화면 텍스트 훅("일본에 이런 데가?"). 인사·인트로 금지.
- **롱폼**: **콜드오픈** — 그 편 하이라이트 3~4컷(3~5초) → 한 줄 제목 → 본편.
- **대장 훅**: 대장의 한마디가 최강 무기. *"제가 20년을 다녔는데, 여긴 저도 처음이에요."* = 권위 + 호기심 갭.

## 3. 페이싱 맵 (롱폼)

| 구간 | 무엇 |
|---|---|
| 0:00–0:10 | 콜드오픈 훅(하이라이트) |
| 0:10–0:30 | 오늘 뭘 볼지 약속(기대 심기) |
| 본편 | 잔잔한 b-roll(맥락) + **2~3분마다 5~10컷 버스트**(이동·리액션·먹방) 교차 |
| 상시 | **5~7초마다 화면 변화**(앵글·b-roll·자막) |
| 엔딩 | 감정 마무리 + 다음 편 훅 + 구독 유도 |

## 4. 컷·b-roll·사운드 규칙

- **컷**: 말 사이 공백·"음…" 제거. 제이컷/L컷(소리 먼저, 화면 나중)으로 매끄럽게.
- **b-roll**: 목적지마다 **히어로 샷 3~5개 필수**(일출·절경·음식·걷는 발·손 디테일). 흔들림 안정화.
- **음악**: **비트에 컷을 맞추면** 몰입 급상승. 저작권 free(유튜브 오디오 보관함·Epidemic Sound). 대사 구간은 음악을 −18dB로 낮춤(덕킹).
- **자막**: 항상(무음 시청 대비). CapCut 자동 자막 + 핵심어만 크게 강조.

## 5. 썸네일·제목 공식 (클릭의 90%)

- **썸네일**: 대장의 **감정 표정** + 절경 + 큰 텍스트 3~4단어. 대비 강하게. 편집만큼 시간을 쓸 것.
- **제목**: 호기심 갭 + 구체 숫자·지명. 예) *"60대 대장이 20명 데리고 간 일본 비경"*.
- **A/B**: 썸네일 2안을 만들어 비교(초기엔 감으로라도 2안).

## 6. 촬영 체크리스트 (편집이 편해지는 촬영)

- [ ] 히어로 샷·b-roll 넉넉히 (편집분의 3배)
- [ ] 같은 장면 **다른 앵글 3개** (와이드·미디엄·디테일)
- [ ] 손·발·음식 **인서트 컷**
- [ ] 대장 **인터뷰/코멘트 한 컷**(그 장소에서)
- [ ] **현장음** 따로 확보(바람·파도·시장)
- [ ] 4K 가로로 촬영 → 쇼츠는 세로 크롭(한 번 찍고 둘 다 사용)

## 7. 편집 학습 루브릭 (레퍼런스·우리 영상 100점 채점)

| 항목 | 배점 | 체크 포인트 |
|---|---|---|
| 훅 (0~10초) | 20 | 인트로 없이 보상부터? 3초 안에 궁금해지나? |
| 페이싱·컷 밀도 | 15 | 5~7초마다 변화? 버스트/잔잔 교차? |
| b-roll·촬영 품질 | 15 | 히어로 샷? 안정화? 다양한 앵글? |
| 음악·사운드 싱크 | 10 | 비트에 컷? 덕킹? 현장음? |
| 자막·텍스트 | 10 | 무음에서도 이해? 핵심어 강조? |
| 스토리·감정선 | 10 | 시작→절정→여운이 있나? |
| 썸네일·제목(CTR) | 15 | 표정+절경+텍스트? 호기심 갭? |
| 호스트 매력·차별성 | 5 | 대장이 있어 '이 채널만'인가? |
| **합계** | **100** | 70+ 준수 / 85+ 우수 |

## 8. 레퍼런스 분석 템플릿 (조회수 잘 나온 영상 1편당 한 장)

```
영상: [제목] / [채널] / 조회수 __ / 길이 __ / 게시일 __
훅(첫 5초): 무엇을 보여줬나?
컷 밀도: 대략 __초마다 변화
b-roll 비중: 상 / 중 / 하
음악: 장르·비트싱크 여부
자막 스타일:
가장 잘한 것 1가지:
★ 우리가 훔칠 것 1가지:
이탈 추정 지점(느낌):
루브릭 점수: __ / 100
```
→ **10~20편 채우면 공통 패턴 = 우리 편집 공식**이 드러납니다(모객글 루브릭을 완료공지로 만든 것과 같은 방법).

## 9. 내 영상 개선 루프 (가장 강력한 스승 = 내 데이터)

- **매 영상**: YouTube Studio **시청 지속률 그래프** 캡처 → 이탈 급감 지점의 편집 원인 분석 → **다음 편에 반영**. (레퍼런스는 참고, 내 이탈 곡선이 정답.)
- **매월**: 조회수·CTR·평균 시청 지속률·구독 전환을 **경영지표 원장(docs/경영지표-원장.csv)에 유튜브 지표로도 축적** → 채널 성장도 같은 대시보드에서 추세로 확인.
