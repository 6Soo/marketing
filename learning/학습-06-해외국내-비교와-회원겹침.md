# 완료공지 학습 ⑥ — 해외 vs 국내 비교 · 회원 겹침 (전략 종합)

> 해외(675 모객글)와 국내(750 모객글)를 나란히 놓고 본 결론.
> **사장님 예측이 맞았습니다 — 두 게시판은 사실상 다른 사업입니다.** 같은 공식을 쓰면 안 됩니다.

## 1. 두 고객층은 이렇게 다릅니다

| 축 | 해외 (djXe) | 국내 (cMl5) |
|---|---|---|
| 실패율(댓글<3) | 45% | **27%** (문턱 낮음) |
| 참가자 / 재참가율 | 1,056명 / 35% | **1,672명 / 47%** |
| 단골(4회+) / 인당 평균 | 137명 / 2.1회 | **386명 / 4.1회** |
| **최다 참여자** | 32회 | **160회** |
| **계절** | 봄 최고 · **겨울 최악** | 봄 최고 · **여름 최악, 겨울 성수기** |
| **체류** | 길수록(5~7박) 유리 | 당일~3·4박 |
| **제목** | 긴 제목 근소 우위 | **짧은 제목 유리** |
| 두각 테마 | (차이 미미) | **크루즈·섬·역사** |
| 즉시 마감 소재 | 검증된 명품 트레킹 | **당일·근거리·이색(견학/팸투어)·저가** |
| 예약 엔진 | 항공 스케쥴·마일리지 할인 | **집결지 버스·신청순 앞좌석·만원회비** |

**해석:** 국내는 크고 충성스러운 **'일상 커뮤니티'**(주 단위로 버스 타고 나서는 단골), 해외는 상대적으로 신중하고 간헐적인 **'큰맘 먹고 가는 여행'**. 두 곳의 성공 공식(학습 ③ 해외 엔진 / 학습 ⑤ 국내 엔진)을 **분리해서** 쓰세요.

## 2. 공통 DNA (양쪽 다 지켜야 하는 것)

- **3노(노쇼핑·노옵션·노팁)**, **A/B 난이도 + 차량 대기**(체력 안심), **대장 전화·카톡 직통**(웹 미숙 배려)
- **시니어 톤**(존댓말·큰 흐름·전문용어 금지), **'대장' 표기**, 환불기준·안전 면책 고지
- **가격 투명**(총액·불포함 명시), **PII·입금권한 규칙** — 어느 쪽이든 불변

## 3. 회원 겹침 — 가장 큰 성장 기회

공개 참가 흔적 기준(비밀댓글 제외라 실제론 더 많음):

- 해외·국내 **둘 다 가는 핵심 회원 382명** — 이분들은 국내 평균 **8.8회**의 초충성 코어(플래티넘).
- **해외만 674명 · 국내만 1,290명.**
- **국내 참가자의 36%만 해외로도 갑니다** (해외 참가자의 23%만 국내로 옴 — 국내는 이미 대부분 커버).

### 💡 1순위 실행: 국내 단골 → 해외 전환

**국내에서 4회 이상 온 단골인데 해외는 한 번도 안 간 분이 221명** 있습니다.
이분들은 이미 우리를 신뢰하는 충성 고객이라, **신규 광고 없이 해외 매출을 키울 수 있는 가장 값싼 명단**입니다.
(반대로 '해외만·국내 안 감'은 37명뿐 — 국내 유치 여지는 적음.)

- **방법:** 국내 단골의 취향(트레킹·힐링·섬·역사)과 이어지는 **입문용 해외 상품**(가까운 일본 단기 트레킹·온천)을, 이분들에게 **카톡으로 먼저 개별 초대**. → 해외의 '초고속 마감' 확률↑, 신규 획득비 0.
- 근거: 학습 ①에서 확인한 해외 재참가 35% + 성공글의 '인접 여행 연계 할인'이 이미 통하고 있었음.

## 4. 이 학습을 시스템에 붙이는 다음 단계 (제안)

1. **관리자 화면 "추천 초대 명부"** — 새 여행을 열 때 테마·지역으로 단골을 자동 추출해 카톡 초대 대상 리스트업. (명부는 DB에 준비됨.)
2. **"스펙 입력 → 모객글 초안 자동 생성"** — 해외/국내 엔진(학습 ③·⑤)을 관리자 화면 버튼으로. 대장은 손질만.
3. **지역 자동분류기 개선** — 국내 표본의 라벨 오분류를 본문 기반으로 교정(후속 데이터 정합성 과제).
4. **KPI 분리** — 국내는 '반응(댓글)'과 '실모객(확정 인원)'을 별개 지표로 관리(학습 ⑤ 함정 참고).
