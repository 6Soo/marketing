# 완료공지 학습 ⑤ — 국내 성공·실패 패턴 + 국내 전용 자동생성 엔진

> 근거: 국내 완료공지 게시판(cMl5) **모객글 750건** + 댓글 50,341개 + 대장 확정 명단 1,180건.
> 성공점수 = 예약반응 65% + 모집속도 35%(데이터가 정한 비중). 실패기준: 댓글 3개 미만 → **202건(27%)**.

---

## 한 줄 결론

**국내는 "집에서 가까운 · 당일 · 초저가 · 이색"이 순식간에 마감됩니다.** 해외의 "봄·장기·완성형" 공식을 그대로 쓰면 안 됩니다.

## 1. 국내가 데이터로 증명한 것 (해외와 다른 축)

1. **계절이 정반대.** 봄 0.08 › 가을 0.05 › 겨울 0.04 › **여름 −0.12(최악)**. 국내 회원은 여름 더위·성수기를 피하고, **겨울(얼음트레킹·설경)은 오히려 성수기**입니다. (해외는 겨울이 최악이었습니다.)
2. **제목이 정반대.** 짧음(<25자) 0.11 › 중간 0.01 › 긺(40+) −0.03. 국내는 **짧은 제목**이 유리 — 지명을 `&·+@`로 길게 나열하면 손해.
3. **크루즈·섬이 두각.** 크루즈 0.40(테마 최강) · 역사문화 0.08 · 야생화 0.08 · 섬 0.08. 해외는 테마 차이가 없었는데, 국내는 **섬을 유람선/전용선/크루즈와 묶는 조합**이 반응을 크게 끌어올립니다.
4. **실패 문턱이 낮다.** 댓글<3 실패가 27%(해외 45%). 근거리·단골·저가 덕에 웬만하면 최소 반응은 나옵니다.
5. **충성도가 압도적.** 참가자 1,672명, **재참가 47%, 단골 386명, 인당 4.1회, 최다 160회.** 해외(35%·137명·2.1회·32회)보다 훨씬 두텁습니다.

## 2. 국내 초고속 마감의 공식 (본문에서 뽑은 관찰 패턴)

- **이색·희소 이벤트가 1순위 트리거** — "처음 보는 것"이 첫 3일을 폭발시킴. 챔피언: **에이스침대공장 견학 팸투어**(회비 단돈 2,000원, 첫 3일 예약 95건). 한탄강 얼음트레킹, 라드라비 복합문화공간 등.
- **'가까운·당일·저녁이면 귀가' 근거리 프레이밍**을 첫 줄에 — "대부도서 50분", "서울서 한 시간 반".
- **초저가 회비('만원의행복' 11,000원, 견학 후원금 2,000원)** 를 전면에.
- **집결지(지하철 출구+시각) + 대형버스 + '신청순 앞좌석 배정(이틀 유효)'** — 이 좌석 선착순 규칙 자체가 국내 고유의 예약 엔진(긴박감).
- **선택형 멀티트랙(N색 피서·완주/반주·팀 나눔)** 으로 체력 불안 제거.
- **'회원님 초청·특별기획·감사'** loyalty 프레이밍 — 단골 47% 기반이라 국내에서 특히 강력.

## 3. ⚠ 가장 중요한 함정 — "댓글 폭발 ≠ 실제 모객 인원"

국내 성공점수는 반응(댓글)에 민감해서 **당일·저가글이 상위**를 차지하는데, 정작 확정 인원은 작습니다.

| 글 | 댓글 | 실제 확정 인원 |
|---|---:|---:|
| 자월도 야생화 **당일** | 💬265 | **2명** |
| 만원의행복 당일 | 💬161 | 2명 |
| 침대공장 견학 팸투어 | 💬150 | 12명 |
| 부산 아난티 **2박3일** | 💬139 | **84명** |
| 흑산도·홍도 2박 | 💬139 | 29명 |

→ **목표를 먼저 정하세요.** "카페를 북적이게(반응·마감속도)" 하려면 당일 저가·이색글, **"실제 매출·인원"** 을 원하면 **섬·크루즈 2~3박**입니다. 둘은 다른 상품입니다.

## 4. 국내 실패 패턴

- **여름을 그냥 관광으로 판 글** — 반드시 '피서(계곡·얼음골·오지·시원한 섬)'로 리프레임해야 삽니다.
- **멀리·오지섬·4박+ 같은 '해외급 접근 마찰'** — 국내여도 해외형 실패를 따름(신년 포항 4박, 청송 온천 등 댓글 0).
- **이색·희소·타이밍 후크가 빠진 평범한 근거리 여행.**

## 5. 국내 전용 자동생성 엔진

해외 공식의 뼈대(3노·A/B 난이도·대장 카톡 직통·존댓말)는 그대로, **4곳을 국내 레버로 치환**합니다.

| 단계 | 해외 | → 국내 치환 |
|---|---|---|
| 첫 줄 후크 | 검증된 명품 목적지+시즌 정당화 | **근거리·당일**('집에서 가까운·저녁이면 귀가') + **이색·희소**(견학·팸투어·전용선·한정) |
| 제목 | 지명 &·+@ 나열 + [항공/박수] 대괄호, 40자+ | **25자 미만**, 날짜(요일)+목적지+훅 하나 |
| '이동' 단 | 한낮·직항·국적기 항공 스케쥴 | **집결지(지하철 출구+시각)+대형버스+신청순 앞좌석(이틀 유효)** |
| 가격 | 총액(예약금)+마일리지 할인 | **초저가 회비(만원의행복)** 전면, 여권·항공료 문구 삭제 |
| 싱글룸 | 제목·첫 줄에 상수 | **숙박 전환 글에만** (당일글엔 무의미) |
| loyalty | (없음) | **'회원 초청·특별기획·감사'** 신설 |

**제목 템플릿:** `[가치라벨: 조기마감·회원초청·만원의행복·특별기획 中 1] {월}/{일}({요일}) {목적지}·{훅 하나} [당일/1박·버스]` (25자 미만)
