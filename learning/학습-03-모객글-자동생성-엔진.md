# 완료공지 학습 ③ — 모객글 자동생성 엔진

> 성공·실패 데이터를 "다음 여행 모객글을 뽑아내는 공식"으로 바꾼 것.
> 스펙(목적지·박수·시즌·항공)만 넣으면 이 틀로 초안이 나옵니다. **초안일 뿐, 대장이 최종 손질**하세요.

---

## 공식 (한 문단)

성패는 테마가 아니라 재현 가능한 **안심 형식**의 반복에서 갈립니다. 최대 동력은 예약반응(댓글, 없으면 실패)이므로 모든 글은
**[감정 데우는 첫 줄 후크 → 시니어 3대 불안(룸메·체력·이동피로) 선제 해소 → 가격은 뒤에·절약경로 즉시 → 소수정예 + 카톡 직통]** 순서로 '댓글을 부르도록' 설계합니다.
**안전패 스펙** = 검증된 명품 목적지 + 봄 시즌 + 셀프발권 없는 완성형(대장 발권) + 전일 기본 싱글룸.

## 제목 템플릿 (빈칸 채우기)

```
[{가치라벨: 마감·특별기획·파격특가 中 1}] {출발월}월{출발일}({요일})~{종료일}/{명소1}&{명소2}&{명소3}+@{보너스지}[{항공사}/{박수}박·전일 기본싱글룸] {감성수식+테마}
```
- 날짜(요일)로 시작 → 명소를 `&`로 3개+ 병렬 → `+@` 보너스지 → 대괄호에 스펙 압축.
- 낯선 목적지는 '○○의 알프스/우유니' 별칭으로 위상 격상.
- **국내는 항공사 대신 `[KTX/2박]` 식으로 치환.**

## 본문 순서 (10단)

1. **첫 줄 후크** — 핵심 셀링포인트를 [대괄호] 한 줄로(시즌 정당화 또는 페인포인트 해소)
2. **여행지 매력** — 풍경·명소를 길게, 제3자 권위 1개(익숙한 곳에 한해)
3. **반(反)패키지 차별점** — 3노 1차 선언 + '우리세대 맞춤'
4. **시니어 3대 불안 해소** — 기본 싱글룸 + A/B/C 난이도·차량 대기 + 이동피로 구체 증명
5. **항공 스케쥴** — 편명·시각 명시, 한낮·직항·국적기 강조
6. **여행 경비** — '총 000원(예약금 000원)'을 항공 뒤에 + 마일리지·연계 할인 바로 옆에 + '늦으면 항공료 오름' 저압 긴급성
7. **예약 절차** — 계좌 + '예약금 후 여권 사본 카톡'(온라인 폼 아님)
8. **포함/불포함 대비** — '숨은 비용 없음' + 말미 3노 2차 재확인
9. **날짜별 일정** — 큰 흐름 위주, (A/B) 난이도·자유식 여백
10. **기타 고지** — 환불기준·안전 면책 + '기획·진행: 대장 아슬란(전화·카톡)' 재노출

## 발행 전 체크리스트 (대장이 훑는 15항)

- [ ] 예약(댓글) 유발장치 3개+ — 카톡 직통·[마감] 희소성·'자리 곧 참' 소프트 긴급성
- [ ] 3노를 첫 문단과 포함/불포함 말미에 2회 못박음
- [ ] 전일 기본 싱글룸을 제목·첫 줄에 노출
- [ ] A/B/C 난이도 + 차량 상시 대기 명시
- [ ] 이동피로 최소화를 구체 사례로 증명(추상어 금지)
- [ ] 제목이 날짜 리드 + 명소 병렬 + 스펙 대괄호 + 가치라벨
- [ ] 가격을 항공 뒤 '총액(예약금)'으로, 절약경로를 바로 옆에
- [ ] **위험 스펙 보정** — 가을·겨울·일본 비인기면 시즌 후크를 더 세게 + 5박·완성형으로 기본점 확보
- [ ] 제3자 권위 1개(익숙한 곳만)
- [ ] 자유식·자유선택 여백('원하시는 분만')
- [ ] 대장 이름·전화·카톡 반복, 예약은 '여권 카톡' 절차
- [ ] 환불기준·안전 면책·할인 중복불가 고지
- [ ] 전 문장 존댓말·전문용어 없이 큰 흐름
- [ ] 인솔자는 '대장' 표기(영문 guides/leader는 유지)
- [ ] 입금상태 변경 문구 없음(사장 전용) · 잔금 독촉 없음 · PII 원문 미기재

> ⚠ **정직한 주의:** 위 12개 레버 중 '봄 시즌·셀프발권 회피·검증된 개별 목적지'는 데이터로 증명됐지만,
> '3노 반복·싱글룸·긴 제목·권위 나열'은 거의 모든 글의 공통 상수라 **성패를 가른다고 증명되진 않았습니다.**
> 브랜드 색을 지키는 안전한 관행으로 쓰되, "이것만 넣으면 성공"이라고 과신하지는 마세요.
