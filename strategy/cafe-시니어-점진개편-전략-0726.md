# cafe.foresttour.kr 시니어 점진 개편 전략

## 1. 역할

`cafe.foresttour.kr`은 숲길여행이 가장 오래 축적해 온 관계 자산이다.
개편의 목적은 새 디자인을 보여주는 것이 아니라 다음 두 결과를 만드는 것이다.

1. 기존 시니어 회원이 더 자주, 더 편하게 카페를 이용한다.
2. 신규 시니어 회원이 가입 후 길을 잃지 않고 첫 행동까지 완료한다.

두 집단은 비슷해 보이지만 해결해야 할 문제가 다르다.

| 대상 | 현재 위험 | 우선 목표 | 피해야 할 것 |
|---|---|---|---|
| 기존 회원 | 익숙한 위치·용어가 바뀌면 이용 중단 | 변화 저항 없이 가독성·탐색·재방문 향상 | 메뉴 재배치, 명칭 변경, 전면 리뉴얼 |
| 신규 회원 | 가입·등급·게시판·신청 방식이 낯섦 | 첫 방문에서 다음 행동을 이해하고 7일 내 안착 | 설명 없는 카페 홈 투입, 긴 매뉴얼 |

## 2. 절대 원칙

- 다음 카페 원본은 핵심 자산으로 유지한다.
- 한 번에 한 가지 작은 변화만 출시한다.
- 기존 메뉴명과 신청 관습을 먼저 보존한다.
- 되돌릴 수 없는 변경은 하지 않는다.
- 새 기능은 기본 동선을 막는 팝업보다 선택 가능한 보조 장치로 제공한다.
- “더 현대적”보다 “더 잘 보이고 덜 헤매는가”를 판단 기준으로 삼는다.
- 기존 회원과 신규 회원의 지표를 섞지 않는다.

## 3. 권장 구조: 원본 카페 + 보조 현관

### 기존 회원

익숙한 `다음 카페 바로가기`를 첫 번째 선택으로 계속 제공한다.
기존 게시판, 닉네임, 댓글 신청 방식은 바꾸지 않는다.

선택적으로 다음 보조 기능만 덧댄다.

- 큰 글씨로 여행 글 보기
- 현재 모집 중인 여행만 보기
- 내가 다음에 해야 할 일 확인
- 문의 전화와 예약 도우미 연결

### 신규 회원

카페 홈으로 바로 떨어뜨리지 않고, 짧은 `처음 오신 분 안내`를 거친다.

1. 숲길여행 카페가 어떤 곳인지 한 문장으로 설명
2. 카카오/다음 로그인과 가입 상태 확인
3. 닉네임·등급·게시판의 의미를 화면 하나씩 안내
4. `모집 중 여행 보기` 또는 `첫 인사 남기기` 중 하나만 선택
5. 첫 행동 후 원본 카페로 연결

신규 안내는 기존 회원 화면에 강제로 노출하지 않는다.

## 4. 단계별 실행

### 0단계 — 기준선 관찰 (1~2주)

화면을 바꾸기 전에 다음을 측정한다.

- 카페 도메인 진입 수와 원본 다음 카페 이동률
- 모집글 조회 대비 예약 도우미 이동률
- 신규 가입 후 7일 내 첫 조회·댓글·예약 비율
- 기존 회원의 월간 재방문 빈도
- 전화·문자에서 반복되는 “어디를 눌러야 하나” 질문
- 기기별 글자 크기·가로 스크롤·로그인 이탈 문제

### 1단계 — 무위험 가독성 개선

원본 카페 동선은 그대로 두고 보조 화면에만 적용한다.

- 본문 기본 글자 18~20px, 줄간격 1.7 이상
- 버튼 높이 48px 이상, 한 화면의 주요 행동 1개
- 전문용어 대신 `여행 보기`, `신청하기`, `카페에서 댓글 보기`
- 전화번호는 누르면 전화 연결
- 뒤로가기와 `원래 카페로 돌아가기`를 항상 보이게 유지
- 게시글 이미지·표의 모바일 가로 넘침 제거

### 2단계 — 기존 회원 이용률 향상

- `지금 모집 중`, `곧 출발`, `여행 후기` 세 묶음만 제공
- 최근 본 여행과 다음 할 일을 첫 화면에 표시
- 마감·변경 공지는 날짜와 상태를 큰 글씨로 표시
- 카페 알림 설정 방법을 원할 때만 한 화면으로 안내
- 게시글을 읽은 뒤 원본 댓글 위치로 정확히 연결

출시 단위는 한 번에 하나다. 2주간 이탈·문의 증가가 없을 때 다음 항목으로 간다.

### 3단계 — 신규 회원 안착

- `처음 오셨나요? 3분 안내` 진입 선택지
- 가입 전/가입 완료/등급 대기 상태별 다른 안내
- 첫 방문에서 보여줄 게시판을 2개 이하로 제한
- 첫 성공 행동을 `여행 글 1개 읽기`처럼 작게 정의
- 1일·3일·7일 후 미완료 단계만 다시 안내

### 4단계 — 세대별 연결

- 20~40대는 인스타그램 → foresttour.kr → 예약/문의로 연결하고 카페를 강요하지 않는다.
- 시니어 신규 유입은 검색·지인 추천·문자 → 카페 보조 현관 → 원본 카페로 연결한다.
- 기존 시니어는 저장한 카페 주소와 기존 알림 습관을 계속 사용하게 둔다.

## 5. 실험 안전장치

- 신규 보조 화면은 처음에 10% 또는 특정 링크 유입에만 노출한다.
- 기존 회원에게는 항상 `기존 카페로 바로 가기`를 가장 눈에 익은 위치에 둔다.
- 메뉴 순서나 명칭 변경은 이용자 인터뷰 없이 하지 않는다.
- 전화 문의, 뒤로가기, 원본 카페 복귀가 증가하면 즉시 이전 상태로 되돌린다.
- 클릭률 상승보다 예약 오류·신청 누락·로그인 혼란이 없는지를 먼저 확인한다.

## 6. 핵심 지표

### 기존 회원

1. 주간·월간 재방문 회원 수
2. 모집글 도달률
3. 글 조회 후 댓글 또는 예약 이동률
4. 같은 문제의 반복 문의 건수
5. 원본 카페 복귀율과 오류율

### 신규 회원

1. 첫 방문 → 가입 완료율
2. 가입 → 첫 글 조회 완료율
3. 가입 후 7일 내 첫 댓글·문의·예약률
4. 7일·30일 재방문율
5. 단계별 이탈 위치

## 7. 첫 구현 우선순위

1. 현재 도메인·원본 카페·예약 도우미 사이의 유입 추적 정비
2. 선택형 `큰 글씨로 보기`와 `기존 카페로 바로 가기` 병행
3. 신규 회원 전용 3단계 안내
4. 모집 중 여행만 모은 단순 목록
5. 지표가 개선된 기능만 기존 회원 전체로 확대

이 계획에서 성공은 화면이 새로워지는 것이 아니라, 기존 회원이 불편을 느끼지 않으면서 더 자주 이용하고 신규 회원이 첫 주 안에 스스로 다음 행동을 할 수 있게 되는 것이다.
