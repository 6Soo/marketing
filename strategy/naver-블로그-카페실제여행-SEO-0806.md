## 3. 한 편의 글 구조

### 제목

`가루이자와 여름 여행 | 카페 현장 사진으로 따라간 숲길·미술관`

### 도입부

첫 번째 사진 뒤 첫 글은 방법 설명 없이 장소의 첫 장면으로 시작한다. 사진보다 앞에 긴 도입 문단을
두지 않는다.

1. 가루이자와 여름 여행이라는 핵심 주제
2. 구 미카사호텔·숲길처럼 첫 사진에서 확인되는 구체적인 장소
3. 다음 사진으로 이어지는 이동 감각

### 말투·사진 배치 규칙

- 공개 본문은 `-습니다`체가 아니라 `-해요`체를 기본으로 쓴다. `-네요`, `-이에요`, `-할게요`
  같은 자연스러운 변형은 허용하고, 원문을 직접 인용하는 부분만 원문 어미를 보존한다.
- 제목 다음부터 `사진 01 → 글 01 → 사진 02 → 글 02`를 반복한다. 사진 9장과 글 9개를
  1:1로 짝지으며, 본문을 먼저 몰아 넣거나 사진을 마지막에 몰아 넣지 않는다.
- 공개 본문에는 장면 설명만 넣는다. 원문·권리·검수 근거는 내부 원고·발행 기록에 두고,
  공개 상품 안내가 필요할 때만 마지막 글 뒤 끝 블록에 둔다.
- 공개 본문에서 작성자·출처·편집 과정을 해설하는 문장을 쓰지 않는다. `작성자가 새로 다녀온
  후기가 아니라`, `카페에 남은 실제 여행 장면을 다시 엮은 기록`, `메모가 남아 있어요` 같은
  표현은 금지한다.
- 발행 직전 SmartEditor DOM에서 제목 다음 컴포넌트가 `image, text` 반복인지, 사진·글 수가
  같은지, `-습니다`체가 없는지 확인한다.

### 본문 순서

1. 구 미카사호텔 표지와 건물 — 사진에 보이는 표지·건축만 기술
2. 센가다키폭포계곡길 — 2141 원문의 코스명과 실제 숲길 사진 연결
3. 가루이자와 신미술관 — 2142 첨부사진의 외관·서가·전시장
4. 숲 사이 설치작품 — 사진에 보이는 색·형태만 기술
5. 고원 도시 메모 — 2142의 1,000여m·폭염·열대야 메모를 출처와 함께 요약
6. 바깥 풍경과 이동 — 물가·잔디·건물의 연속 장면
7. 복날 와규구이 — 2143의 메모와 실제 식사 사진 연결
8. 마무리 — 카페 사진과 메모가 남긴 여행의 순서 요약

각 사진 다음에는 해당 장면을 설명하는 해요체 글을 붙인다. 출처·권리 표기는 마지막 글 또는
마지막 뒤 끝 블록에만 둔다. 사진의 의미를 과장하는 긴 감상문은 붙이지 않는다.

## 4. 사진·권리 게이트

`카페에 올라왔다`는 사실은 네이버 블로그 재사용 권리와 동일하지 않다. 공개 전 다음을
모두 확인한다.

- 원문 게시글 URL과 첨부파일 식별자
- 원본 크기와 최종 업로드 파일 SHA-256
- 촬영자 또는 카페 운영 주체 확인
- 네이버 블로그·자사 사이트 재사용 허락
- 사진 속 인물 식별 가능 여부와 필요한 동의
- 광고가 붙은 화면 캡처, 지도·고도 앱 화면, 사진에 없는 장소를 합성한 이미지 제외
- 사진을 `우리 사진`이라고 부를 수 있는지, 아니면 `카페 첨부사진`이라고만 표기할지 결정

현재 9장 후보는 `_stage/naver-blog/karuizawa-cafe-record/images/`에만 임시 보관한다.
이번 9장 후보는 회사 자산으로 확인되었으므로 `company-owned-approved`로 기록하고
별도 재허락을 기다리지 않고 발행한다. 공개할 때는 카페 원문 게시글과 회사 자산임을
발행 기록에 남긴다. 회사 자산으로 확인되지 않는 사진만 발행 직전에 제거한다.

## 5. 상품 연결 게이트

현재 공개 모집 원문은 [10월 가루이자와·이카호 일정](https://cafe.daum.net/sixsungwon/fNof/3)이다.
본문에 가루이자와, 센가타키, 옛거리, 쿠모바호, 존 레논 호텔이 명시되어 있어 일부
공통 동선은 확인된다. 그러나 세존미술관은 해당 공개 일정에 명시되어 있지 않다.

따라서 첫 글에는 상품 CTA를 넣지 않는다. 다음 중 하나가 충족될 때만 연결한다.

1. 공개 일정 원문에 글의 핵심 사진 장면과 동일한 동선이 명시됨
2. 글의 범위를 공통 동선으로 좁히고, 세존미술관 장면은 별도의 과거 기록으로 명확히 분리함
3. 연결 문구가 `현재 같은 여행을 판매 중`이 아니라 검증된 범위의 `관련 공개 일정`임을 명시함

동선이 완전히 맞지 않으면 상품 링크 없이 여행 기록으로 발행한다. 실제 여행 기록과
현재 판매 상품은 서로 다른 근거로 관리한다.

## 6. 사람 글 검수

Sol 검수에서 다음을 문단별로 확인한다.

- 카페 원문에 없는 `내가 느꼈다`, `직접 걸었다`, `맛이 깊었다` 같은 체험 동사 제거
- 동일한 길이와 어미가 반복되는 문단 해체
- `고요한`, `숨이 멎는`, `감성적인` 같은 상투 감각어를 사진의 구체적 디테일로 교체
- 한 문단에 정보·감상·판매를 모두 넣지 않기
- 원문 메모가 짧은 곳은 억지로 서사를 늘리지 않기
- 캡션이 본문을 반복하지 않고 사진에서 확인되는 사실을 보태기
- 작성 방식·출처 고지 문장이 공개 본문에 남지 않았는지 확인

`FAIL`이면 해당 문단만 다시 쓰고 같은 검수를 반복한다. 사람이 쓴 것처럼 보이게 만들기
위해 실제 기록 밖의 내용을 추가하지 않는다.

## 7. 측정

- 공개 직후: 비로그인 화면에서 제목·사진 수·순서·원문 링크·권리표시 확인
- D+3: 게시 상태, 제목 검색 발견 여부, 사진 로딩·원문 링크 오류를 기록한다. CTA는
  링크 클릭 또는 상품 페이지 유입이 확인되지 않아도 유지하지 않고, 권리·동선 근거가
  빠진 것이 발견되면 즉시 보류한다.
- D+7: 네이버 블로그 Creator Advisor의 조회수, 검색 유입수·검색어, 평균 노출을
  기록한다. 조회·검색 유입이 모두 0이면 제목과 첫 문단을 1회만 조정하고, 키워드
  반복으로 보이게 늘리지 않는다. CTA는 상품 페이지 유입이 있고 글의 핵심 장면과
  상품 동선이 여전히 일치할 때만 유지한다.
- D+28: 같은 검색어의 유입 지속 여부, 저장·공감·댓글 등 확인 가능한 반응, 유입
  검색어의 의도를 기록하고 다음 글의 독립 질문을 결정한다. 유입이 없거나 다른
  의도라면 같은 제목을 복제하지 않고 새 글로 분리한다. 상품 동선이 불일치하거나
  권리 근거가 사라지면 CTA를 제거한다.

`foresttour.kr` 웹문서의 Search Advisor 노출·클릭은 네이버 블로그 통계와 섞지 않는다.
Search Advisor의 노출·클릭 리포트는 VIEW·블로그 검색영역을 포함하지 않는다고 명시되어
있으므로, 블로그 성과의 직접 대체 지표로 쓰지 않는다.
