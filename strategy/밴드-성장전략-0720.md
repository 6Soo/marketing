# 네이버 밴드 성장 전략 — 신규 회원 유치 (2026-07-20)

> 자매밴드 [숲길따라 감성여행] Daum Cafe(공개밴드·멤버 약 1,636) 복원 계기.
> 독립 조사 3건(카페→밴드 트렌드 / 밴드 유입 메커니즘 / 밴드 오픈API) 종합. 출처는 각 절 말미.
> ⚠ 법·약관·광고 단가 등은 밴드 공식 약관·광고센터에서 최종 확인 필요(봇차단으로 일부 원문 미열람).

## 0. 결론 (정직한 정정 포함)

**"여행 카페가 밴드로 옮겨간다 → 밴드로 신규 유치"는 절반만 맞습니다.**

- ✅ **맞는 절반**: 다음카페 쇠퇴는 확실하고, 밴드는 50~70대 도달·모임 운영에서 국내 1위 채널이다. → **밴드 복원 방향은 옳다.**
- ⚠ **틀린 절반**: 밴드는 **검색 발견성이 약해** '신규 발견·모객' 채널로는 약하다. 밴드의 진짜 강점은 **'모임 운영·전환·알림'**이지 '신규 획득'이 아니다. 카페 이탈층도 밴드로 직행하지 않고 카톡 단톡방·오픈채팅·소모임·유튜브로 분산된다.

→ **전략**: 밴드는 **강점(중장년 도달·일정 운영·알림)에만** 쓰고, **신규 발견은 검색 노출 채널을 병용**한다. "밴드 하나로 신규가 밀려온다"는 기대는 접는다.

## 1. 트렌드 판정 — 부분적(밴드의 중장년 도달력만 강함)

**다음카페 쇠퇴 (근거 강함)**
- 카카오가 다음을 분사·양도 완료(2025.12, 양도가 70억). 다음 검색 점유율 **2.89%**(네이버 65%·구글 29%).
- 서비스 축소(카페 선물하기 종료, 개방형 '테이블' 종료 수순), 실사용자 3년 새 약 70만↓(323만→252만).

**밴드 위상 (근거 강함)**
- MAU 약 1,700만(국내 SNS 2위). **이용자 40·50대 비중 약 53%** — 인스타·틱톡 대비 압도적 중장년.
- 세대 선호 1위 앱: **40대·50대·60대 모두 '밴드'**(와이즈앱). 성장 동력이 '소모임(등산·취미)'.

**약한 고리 (확인 불가/반대 근거)**
- "여행·등산 커뮤니티가 **카페→밴드로 이동**한다"는 직접·정량 근거는 부족.
- 밴드는 그룹 콘텐츠가 **외부 검색 색인이 약함** → 신규 발견 취약. 취미모임 앱 '소모임'(500만 다운로드) 등으로 시니어 산행 수요가 분산.
- 조선비즈 진단: 신규 유입 둔화는 **밴드·카페 공통**, 이탈층은 카톡/오픈채팅으로.

## 2. 채널 역할 분담 (핵심)

| 채널 | 역할 | 강점 | 쓰는 법 |
|---|---|---|---|
| **다음카페**(본진) | 아카이브·예약·상세 후기 | 회원 11,000·기존 자산 | 그대로 유지(회원 이동 금지) |
| **네이버 밴드** | **모바일 유입 전환·일정 알림·현장 소통** | 50~70대 도달·모임 운영 | 요약 + 카페/예약 링크. 중복 게시 금지 |
| **신규 발견 유입구** | 신규 획득 | 검색·대규모 도달 | 네이버카페(검색 노출)·카카오 오픈채팅(일 1,200만·여행방)·GFA 성과형 광고 |

**원칙**: 밴드는 '신규를 잡는 그물'이 아니라 '잡은 사람을 눌러앉히는 마당'. 신규는 검색 노출 채널로 데려오고, 밴드에서 일정·알림·소통으로 단골로 전환.

## 3. 실행 체크리스트 (밴드 세팅·운영)

1. **공개 설정 = '공개' + 가입 승인제** — 검색·'밴드 찾기' 노출은 켜고, 승인제로 광고·스팸 계정 차단. (비공개는 유입 0)
2. **밴드명·소개·키워드·지역을 검색 겨냥** — 예: "숲길따라 감성여행 · 5060 트레킹 · 노옵션 노쇼핑 노팁 · 서울 출발". 큰 글씨 커버(4:3·10MB 이하)에 3무 정책 명시.
3. **카페 ↔ 밴드 동선** — 카페 대문·모집글에 밴드 **초대 링크·QR** 상시 배치(모바일 손님을 앱으로). `?from=` 식별자로 유입원 계측.
4. **정기 콘텐츠 리듬** — 모집은 **일정(참석 응답 버튼)**, 후기는 사진앨범, 다음 여행은 투표. 장문 지양·존댓말·큰 글씨·사진 위주(시니어 친화).
5. **신규 확보는 GFA 성과형 광고** — 5060·수도권·여행/등산 관심사 타겟, 클릭당 소액 테스트. **'새소식(알림) 광고'는 신규가 아니라 기존 멤버 재방문용** — 헷갈리면 예산 낭비.
6. **공동리더 위임** — 카페+밴드 병행은 부담이 크므로 신규 대장(예: 엘레나)에게 공동리더 권한(일정·후기 관리).
7. **스팸·사칭 방어** — 가입 승인 시 간단 확인, 신규 초기 글쓰기/링크 권한 제한, 홍보 계정 즉시 신고·강제탈퇴 공지.
8. **상업 모객 리스크 정리** — 자사 밴드에 자기 여행 모집은 통상 허용이나, 대량 유료 홍보는 밴드 **공식 모객광고 상품**으로. 순수 판매 채널로 비치지 않게 '커뮤니티(모임)' 형식 유지. 약관 원문 최종 확인.

> 출처: 나무위키 밴드(SNS), raonblog(초대·유효기간), 마케팅인사이드(광고 종류 inside.ampm.co.kr/insight/4269), i-boss(새소식 광고), 등산동호회 운영규칙(ipcjeju.com/5963), 다나와 DPG(공동리더), 고구마팜(시니어 마케팅·시놀 9만).

## 4. 일정 게시 자동화 (밴드 오픈API 조사 결과)

- ❌ **일정(이벤트) 생성은 API 불가** — 밴드 오픈API에 캘린더 일정·신청자 모집·참석 확인 엔드포인트가 **없음**(앱/웹 UI 전용).
- ✅ **텍스트 '글'은 API 자동게시 가능** — `POST openapi.band.us/v2.2/band/post/create`(access_token·band_key·content·do_push). 자사 밴드·본인 계정 개인 토큰은 별도 승인 없이 발급, 토큰 수명 ~10년. 사진 첨부 미지원, 연속 대량은 쿨다운(에러 1003) 제한.
- ⚠ RPA(화면 매크로) 완전자동은 약관 위반·계정 제재·유지보수 리스크로 비권장.
- **권장 = 반자동**: 투어 데이터(코스북) → **일정 초안(제목·설명·일시·장소) 자동 생성** → 사람이 밴드 '일정 만들기'에 붙여넣고 신청받기·참석확인 토글 → 완료. 보조로 **모집 요약 '글'은 API 자동게시(푸시 알림)**해 일정으로 유도.
- 대외 게시라 최종 발행 클릭은 사람이(권한·보안 불변식: 외부 발송은 사람 승인).

> 출처: developers.band.us/develop/guide/api(전체 엔드포인트 목록), .../write_post, .../get_authorization_code_from_user, .../handle_errors, BAND 모객광고 가이드 PDF.

## 5. 리스크 & 기회

- **기회**: 다음카페 쇠퇴(분사·축소)는 본진 리스크이자, 핵심 자산(회원·모집글)의 **백업·다채널화를 서두를 근거**. 밴드는 그 다채널의 중장년 축.
- **리스크**: 밴드만 믿고 신규 유치를 기대하면 실망 — 발견성 약점. 반드시 검색 노출 채널과 병용.
- **불변**: 회원을 어디로도 옮기지 않는다. 밴드는 카페 밖 신규 접점 + 기존 회원 편의(알림)용이지, 카페 대체가 아니다.
