# 이정표 × 카페 — "이정표 쓰러 카페에 온다" UX 설계 (2026-07-22)

> 목표(사장 구상): 회원이 이정표를 쓰려고 **카페를 연다** → 카페 체류·재방문 증가 + 이정표 유입.
> 배너 2개 병행은 모바일 대문에서 서로 잠식(cannibalization) → **배너 대신 글 형태**로 전환(사장 결정).

## 핵심 통찰 — 시니어의 '홈 화면'은 이미 카페다

시니어는 북마크·앱 설치·주소 입력이 약하다. 대신 **매일 여는 앱(다음카페)이 곧 즐겨찾기**다.
따라서 "이정표를 쓰는 가장 편한 문"을 카페 안에만 두면, 이정표를 쓸 때마다 카페를 열게 된다.
설계 원칙: **문(링크)·사용법·후기, 세 가지가 전부 카페 안에만 있게 한다.**

## 장치 4가지

1. **문 — 카페가 이정표의 현관**
   소개글(공지 고정) + 대문 버튼 행에 '생활 도우미' 아이템 추가(선택). 모든 링크는
   `https://reserve.foresttour.kr/go/ijeongpyo` 경유 → 클릭이 /admin/traffic '바깥 링크 클릭 × 이정표'로
   집계되고, 어르신 기억 속 경로가 "숲길 카페 → 이정표" 하나로 굳는다.
2. **사용법 — '이런 질문 해보세요'가 카페에만 있다**
   이정표는 빈 입력창이라 어르신은 "뭐라고 쓰지"에서 막힌다. 시니어 단골 문제의 **질문 예시
   문장**(상속·전세 계약·실손보험·연금·건강검진 결과·통신 요금 등)을 소개글에 5개, 이후
   "이번 주 질문 예시" 연재로 카페에 축적 → 쓸 때마다 예시를 베끼러 카페에 온다.
3. **후기 — 댓글 스레드가 커뮤니티 루프**
   소개글 말미에 "어떤 문제를 물어보셨나요? 댓글로 알려주세요" → 후기가 쌓이면 글 자체가
   신뢰 자산이 되고, 연재 소재(다음 질문 예시)도 댓글에서 수확한다.
4. **이름 — 카페 소속감 부여**
   카페 안에서는 '숲길 생활 도우미 (이정표)'로 부른다(김성민 님 동의 전제). 어르신 입말로
   "숲길 카페에 있는 그 도우미"가 되게 — 서비스 기억이 카페 기억에 붙는다.

## 측정 (우리 쪽에서 직접)

- reservation 앱에 `/go/[slug]` 경유 리다이렉트 배포 완료(2026-07-22): 허용 목록 방식,
  미리보기 봇 제외, /admin/traffic에 '바깥 링크 클릭 × 이정표'로 자동 표시.
- 진입점을 나눠 재고 싶으면 TARGETS에 slug 한 줄 추가(예: ijeongpyo-notice / ijeongpyo-post).
- 이정표 쪽 측정은 김성민 님 소관(관여하지 않음). 역방향 링크가 생기면 `?from=ijeongpyo`.
