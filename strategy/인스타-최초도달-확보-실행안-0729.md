## 1. 도달이 0인 기계적 원인 (추측 아님)

### (1) 게시물 5건 전부 캐러셀 — 릴스 0건 ★최대 원인★

2026년 인스타에서 **팔로워 5,000명 미만 계정이 비팔로워에게 닿는 사실상 유일한 포맷은 릴스**다.
릴스 평균 도달률 30.81% / 캐러셀 14.45% / 정지 이미지 13.14%인데, 이 비율은 **팔로워 대비**다.
팔로워가 0이면 캐러셀의 14.45%는 0에 곱해진다 — 구조적으로 0이다.

반면 릴스는 팔로워 0이어도 탐색(Explore) 추천 시스템에 진입한다. 협업 필터링으로 우리 계정과
한 번도 상호작용한 적 없는 사용자에게 노출된다. **캐러셀은 이미 아는 사람에게 보여주는 포맷이고,
릴스는 모르는 사람에게 닿는 포맷이다.** 우리는 아는 사람이 0인데 캐러셀만 5번 올렸다.

### (2) 해시태그 전략이 폐기된 메커니즘에 기대고 있다

현재 게시물마다 해시태그 7개. 그런데 **해시태그 팔로우 기능은 폐지됐고**, 검색 노출은 해시태그가
아니라 **캡션 키워드** 기반으로 옮겨갔다. 권장치도 3~5개다.

게다가 붙은 태그 상당수가 검색량이 사실상 0인 초niche 한국어 조합이다:
`#다테야마구로베알펜루트` `#미치노쿠시오카제트레일` `#다라이부네` `#슈쿠네기`.
이 태그들은 "그 단어를 이미 아는 사람"만 찾는다 — **우리 콘텐츠의 전제가 "아직 모르는 곳을
알린다"인데, 아는 사람만 찾을 수 있는 태그를 달고 있다.** 전략과 수단이 정면으로 어긋난다.

### (3) Trial Reels는 우리가 쓸 수 없다

비팔로워에게만 먼저 노출해 반응을 보는 기능이지만 **팔로워 1,000명 이상**이어야 한다.
0명인 지금은 선택지가 아니다. (1,000 도달 후 재검토)

### (4) 산리쿠가 중복 게시됐다 — 실제 결함

`DbMCkYbEsxd`(7/24)와 `DbPkcaIEwSj`(7/26)의 **캡션 SHA-256이 완전히 동일**하다. 같은 글이
이틀 간격으로 두 번 올라갔다. 코드에는 중복 방지 장치(`assertNotDuplicateCaption`, 최근 25건 대조)가
있지만 **웹 UI 수동 게시가 그 게이트를 우회**했다. 중복 콘텐츠는 추천 시스템에서 불리하게 작용한다.

### (5) 2026 랭킹 신호 — 우리가 설계에 반영하지 않은 것

Mosseri가 확인한 배포 신호 3가지: **시청 시간(watch time)**, **도달 대비 좋아요**,
**도달 대비 전송(sends)**. 이 중 **DM 공유(sends)가 신규 도달에 가장 큰 가중치**를 갖는다.
지금 콘텐츠에는 "친구에게 보내고 싶게 만드는 장치"가 없다. 저장 유도는 있지만 공유 유도는 없다.

## 2. 이미 해제한 것 (2026-07-29 실행 완료)

**릴스 제작 파이프라인이 이 워크스테이션에서 동작하지 않고 있었다.** `cardnews/tools/build-reel.mjs`는
이미 있었지만 ffmpeg를 찾지 못해 실행 자체가 불가능했다(리눅스 경로 `/root/bin/ffmpeg` 기준으로 작성).

- `ffmpeg-static` 설치 → ffmpeg 6.1.1 확보 (`node -e "require('ffmpeg-static')"`로 경로 획득)
- 북알프스 004로 실제 릴스 생성·규격 검증 완료:
  `cardnews/out/northern-alps/reel-cover-a.mp4`
  **1080×1920 · H.264 High · 30fps · AAC 44.1kHz · 25.6초 · 4.3MB** — 인스타 릴스 규격 충족
- 실행법: `FFMPEG_BIN=$(node -e "process.stdout.write(require('ffmpeg-static'))") \`
  `node cardnews/tools/build-reel.mjs cardnews/series/northern-alps --cover=cover-a`

**즉시 릴스로 만들 수 있는 시리즈**: 사도(`verified`, 7장), 북알프스(`verified`, 8장).
히다·산리쿠는 `photoStatus: placeholder`라 게이트에 막힌다 — 사진 교체가 선행 조건.

### 다만 지금 산출물 그대로는 도달에 불리하다 (솔직한 한계)

정지 카드 8장 × 3.2초 = **25.6초 슬라이드쇼**다. 움직임이 없고 첫 1초에 후킹 장치가 없다.
**시청 시간이 1순위 랭킹 신호인데 가장 약한 지점**이다. 기술적으로는 유효한 릴스지만
전략적으로는 경쟁력이 낮다. 개선 방향은 §3-1.

## 3. 실행안 (우선순위 순)

### 3-1. 릴스로 포맷 전환 ★최우선★

같은 콘텐츠·같은 검증 사진을 릴스로 다시 낸다. 새 취재도 새 디자인도 필요 없다 —
**비주얼 계약(기준본 카드)을 그대로 두고 담는 그릇만 바꾸는 것**이다.

시청 시간을 위해 현재 빌더에 필요한 개선(구현 전 사장 확인 권장):
- **길이 단축**: 25.6초 → **8~12초**. 카드 전부가 아니라 4~5장만.
- **정지 → 미세 줌(켄번즈)**: 같은 사진에 아주 느린 확대. 카드 디자인은 그대로.
- **첫 1초 후킹**: 표지 질문("북알프스는 꼭 정상에 올라야만 볼 수 있을까요?")을 첫 프레임에.
- **음악**: 현재 `placeholder-ambient.wav`. 게시 전 라이선스 확인된 트랙으로 교체 필요.
  ※ 인스타 인앱 음악 라이브러리는 API 게시에 붙지 않는다 — 그래서 오디오를 굽는 구조다.

### 3-2. 캡션 SEO로 전환 — 해시태그 의존 축소

- 해시태그 **7개 → 3~5개**로 줄이고, 검색량 0인 초niche 조합 제거.
- 대신 **캡션 첫 문장에 검색 키워드를 자연어로** 넣는다. 검색 노출이 여기로 옮겨갔다.
  - 예: `#다테야마구로베알펜루트` 태그 대신 캡션에 "일본 알프스 트레킹", "가을 일본 소도시 여행"
- 남길 태그 기준: **아직 모르는 사람이 검색할 법한 상위 개념** (`#일본소도시여행`, `#일본걷기여행`)
  + 시리즈 고유 태그(`#나만몰랐던일본`).
  버릴 태그: 그 지명을 이미 아는 사람만 치는 고유명사.

### 3-3. 공유(sends)를 설계에 넣는다

DM 공유가 신규 도달 가중치 1위인데 현재 유도 장치가 없다.
- 마지막 카드의 "저장" 유도 옆에 **"같이 갈 사람에게 보내기"** 한 줄.
- 콘텐츠 자체에 **공유 유발 지점**을 하나 심는다 — 놀라운 사실 한 개
  (예: "한 달에 5만 톤을 처리하던 선광장" 같은 숫자·대비).
- 제0원칙 위반 아님: 여행지의 사실이지 상품 홍보가 아니다.

### 3-4. 중복 게시 차단 — 수동 경로에도 게이트

산리쿠 중복은 웹 UI 수동 게시가 코드 게이트를 우회해 생겼다. API 차단이 풀렸으므로
**수동 게시 자체를 줄이는 것이 근본 해법**이다. 당분간 수동 게시가 필요하다면
게시 전 `assertNotDuplicateCaption` 상당의 확인을 사람이 한 번 수행한다.

## 4. 사장 판단이 필요한 항목

### 4-1. 카페·밴드 회원을 인스타로 끌어올 것인가 — **권장하지 않는다**

카페 11,000명은 최대 자산이지만 **50~60대**다. 인스타 타겟은 20~40대다.
지금 계정은 팔로워가 0이라 초기 팔로워의 반응이 추천 시스템에 그대로 학습된다.
타겟이 다른 팔로워가 초기에 들어오면 **추천 시스템이 우리 콘텐츠를 50~60대 취향으로 분류**해,
정작 닿고 싶은 20~40대에게 덜 노출될 수 있다. 숫자는 오르고 도달은 나빠지는 최악의 조합이다.

→ 카페·밴드는 **foresttour.kr로 보내는 경로로 계속 쓰고**, 인스타 팔로워 확보에는 쓰지 않는다.
   (기존 원칙 "인스타→카페 금지"의 역방향도 마찬가지로 피한다는 뜻)

### 4-2. 릴스 제작 개선(§3-1)을 진행할까

길이·모션·후킹은 화면에 보이는 변화라 사장 취향 영역이다. 반려 이력이 있어 임의로 바꾸지 않았다.
승인하시면 빌더를 개선하고 사도·북알프스 릴스 2편을 만들어 보여드린다.

### 4-3. 음악 트랙 확보

현재 `placeholder-ambient.wav`. 상업적 사용 가능한 트랙이 필요하다.
무료 옵션(YouTube 오디오 보관함 등) 또는 유료 구독 — 저비용 원칙상 무료부터 검토 권장.

## 5. 하지 않기로 한 것

- **팔로워 구매·상호 팔로우** — 참여 신호가 오염돼 추천 시스템에서 회복이 어렵다.
- **게시 빈도만 늘리기** — 포맷이 캐러셀인 한 빈도를 늘려도 도달은 0에 머문다.
- **유료 광고** — 순이익률 4% 구조상 오가닉 검증 전 집행하지 않는다(기존 원칙).
- **Trial Reels** — 팔로워 1,000 미만이라 사용 불가.
