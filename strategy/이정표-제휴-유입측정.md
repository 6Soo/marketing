# 이정표(ijeongpyo) 제휴 배너 — 윈윈 구조와 유입 측정 (2026-07-22)

> ⚠ 갱신(같은 날 사장 결정): 모바일 대문에서 배너 2개가 서로 잠식 → **배너 대신 '글 형태'로 전환**.
> 현행 설계는 `이정표-카페-UX설계.md`가 정본이며, 측정도 UTM(성민 측) 대신 **우리 경유지
> `reserve.foresttour.kr/go/ijeongpyo`**(reservation 앱 배포 완료)로 직접 집계한다.
> 아래 배너·UTM 내용은 예비 보관용.

> 배경: 지인 김성민 님이 만든 **이정표**(https://ijeongpyo.vercel.app) — "생활문제 AI 길잡이".
> 법률·건강·세금·노무·주거·금융 문제를 한 문장으로 물으면 무엇부터 할지 정리해 주는 서비스.
> 전문가 행세 대신 "어디에 먼저 물어볼지"를 정리해 주는 포지션이라 6070 회원층과 정확히 맞음.
> 구상(카톡 2026-07-22): 카페 대문에 배너 → 회원 혜택 + 이정표 유입, 회원이 주변에 퍼뜨리면
> 재사용 유입 — 양방향 윈윈. 무료 토큰 8/24까지, BM 미정 상태.

## 1. 유입 측정 설계

- **배너 링크(확정)**: `https://ijeongpyo.vercel.app/?utm_source=cafe&utm_medium=banner`
- **이정표 쪽(김성민 님, 약 5분)**: Vercel Web Analytics를 켜면 **UTM 파라미터가 자동 수집**됨
  (커스텀 코드 불필요). 대시보드에서 `utm_source=cafe` 필터 = 카페 유입만 분리 조회.
  ① Vercel 대시보드 → 프로젝트 → Analytics 탭 → Enable(무료 티어)
  ② `npm i @vercel/analytics` → 루트 레이아웃에 `<Analytics />` 한 줄 → 배포
- **역방향(선택)**: 이정표에서 숲길로 링크를 걸 일이 생기면
  `https://reserve.foresttour.kr/?from=ijeongpyo` — 우리 /admin/traffic에 자동 집계(신규 코드 자동 수집).

## 2. 배너 실물·게시

- 파일: foresttour 리포 `cafe-kit/images/이정표배너-A안.png`(웜 크림) / `이정표배너-B안.png`(딥 포레스트)
  — 2034×600, 확정 대문배너와 같은 슬롯. 우리 확정 배너(진초록)와 구분되도록 A안(크림) 권장.
- 문구: "막막한 생활 문제, 한 문장만 물어보세요" — 회원 **혜택 프레임**(무료 생활 도우미).
  시니어 친화(큰 글씨·존댓말·"누르시면 바로 열립니다" 명시).
- 게시 방법: 다음카페 대문 **이미지 아이템 + 링크** 방식(HTML 삽입 2025-07-28 종료 —
  사장님-가이드 §3 절차 동일). 링크는 위 UTM 포함 주소 그대로.

## 3. 게시 전 조율 사항 (김성민 님과)

1. **8/24 무료 토큰 종료 후 계획** — 유료화/중단이면 배너 게시 기간을 그 전으로 한정하거나
   연장 여부를 그때 재결정(죽은 링크를 대문에 남기지 않기).
2. **부하 고지** — 카페 회원 약 1.1만 명. 유입이 붙으면 토큰 소진이 빨라질 수 있음을 사전 공유.
3. 도메인 연결 전이므로 링크는 vercel.app 주소 기준 — 도메인이 생기면 배너 링크만 교체.

## 4. 톤 점검 (변화를 팔지 않는다)

- 배너는 카페의 변화가 아니라 **회원 혜택 추가**('넓어짐') — 위반 없음.
- 여행/모객과 무관한 생활 도우미라 상업화 신호 아님. '무료' 명시로 부담 제거.
