## 1. 목표와 현재 사용자 지시

- 이 작업의 지속 목표는 `cafe.foresttour.kr`의 기존 시니어 이용률과 신규 시니어 7일 안착을
  점진적으로 개선하고, 카페 관심이 실제 예약으로 이어지게 만드는 것이다.
- 모바일 기준 화면은 `m.cafe.daum.net/sixsungwon`이며 기존 메뉴명·댓글·전화 습관을 한꺼번에
  바꾸지 않는다. 관찰 → 한 가지 작은 변화 → 반응 검증 → 확대 순서를 지킨다.
- 최신 확정 결정: `직원이 전화로 도움`/고객의 `tel:` 연결은 종료한다. 예약 접수 시 카카오
  알림톡으로 담당 대장에게 신규 예약을 알리고, 담당 대장이 고객에게 카카오톡으로 직접 연락한다.
- 새 실질 작업, 브라우징, 장시간 테스트, 서브에이전트, OCR·대량 LLM 호출은 노트북에서 중단했다.
- cost 프로젝트는 이번 작업에서 수정하지 않았다. 사용자 명시 전 워크북·CSV를 생성하지 않는다.

  `가입 승인 후 닉네임 → 쪽지 보내기`로 교정·파일명 변경이 필요하다.
- reservation 문구 변경은 로컬 검증까지 끝났지만 이 인계 시점 이전에는 아직 배포하지 않았다.
- 승인된 솔라피 템플릿 본문은 저장소 문서 수정만으로 바뀌지 않는다. 고객용·대장용 템플릿을
  솔라피에서 수정·재심사하고 승인된 ID를 환경변수에 반영해야 실제 발송 문구가 바뀐다.

### 미완료

- 다음 카페에 신규회원 안내글을 실제 게시하지 않았다. 신규회원 전용 게시판/권한이 확인되지 않아
  기존 회원 전체 공지로 잘못 노출할 위험을 피했다.
- 신규회원 안내글 주소가 생긴 뒤 승인 후 1:1 쪽지 템플릿의 자리표시자를 실제 URL로 교체해야 한다.
- `/admin/traffic` 표본이 매우 적다. 총 30건 또는 경로별 10건 전에는 UI 결론을 내리지 않는다.
- 최신 reservation 변경의 Vercel 배포와 공개 화면 스모크 검증은 데스크톱에서 이어간다.

## 3. 확정 판단과 판단 대기

### 확정

- 상품 노출보다 자연스러운 발견이 우선이다.
- 카페는 전면 개편하지 않고 모바일·점진 개편한다.
- 기존 회원과 신규 회원의 UI/온보딩은 같은 방식으로 강제하지 않는다.
- 고객이 직원에게 전화하는 보조 경로는 폐기한다.
- 신규 예약을 알림톡으로 받은 담당 대장이 고객에게 카카오톡으로 직접 연락한다.
- 과거 `reserve_help_phone` 통계는 삭제하지 않고 `이전 방식`으로 표시한다.

### 판단 대기

- 다음 카페에서 신규회원 안내글을 어느 게시판·권한으로 노출할지.
- 승인 후 쪽지를 운영자가 매번 수동 전송할지, 공식 지원 범위 안에서 반자동화할지.
- 솔라피 기존 승인 템플릿을 수정할지 새 버전으로 등록할지.
- 대장 연락 약속을 모든 예약에 적용할지, 별도 연락 요청 선택지를 둘지. 현재 구현은 모든 접수에 적용.
