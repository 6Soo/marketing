## 2. 세 모델의 독립 판정

### 공통으로 수용한 결론

- 첫 2문단에서 `누구의 어떤 문제를 어떤 기준으로 풀어 주는 글인지` 보여주는 글이 강해요.
- 사진에 이미 보이는 색·건물·나무를 다시 말하기보다, 사진 밖의 이동·대기·선택·피로·동행자 반응을 붙여요.
- 정보 70~80%, 감정 20~30%가 검색형 글에 안정적이지만, 감정은 `아름다워요`가 아니라 실패·망설임·뜻밖의 발견처럼 장면의 증거여야 해요.
- 문장 길이와 종결을 섞고, 같은 표현을 세 번 연속 반복하지 않아요.
- 제목은 `지역 + 기간/숫자 + 독자 조건 + 얻는 것` 중 세 요소 이상을 쓰고 장소명만 나열하지 않아요.
- CTA는 탐색·계획·예약 중 독자의 단계와 맞춰 한 개만 둬요.
- 사진 하단 문구는 원문을 일괄 삭제하지 않고, 중복을 걷어내어 원문 분량의 65~70%를 목표로 해요.

## 3. 우리 블로그가 덜 매력적인 이유

1. **사람의 선택이 늦게 보여요.** 사도는 자료·공식 링크가 먼저 나오고, 북알프스·가루이자와는
   정확하지만 장소를 바꿔도 성립할 수 있는 감상 문장이 많아요. 비교군은 첫 장면에서 늦잠,
   비, 아이의 반응, 잘못 고른 동선처럼 작고 구체적인 판단을 보여줘요.
2. **사진을 설명하는 글이 사진을 보충하지 못해요.** `무엇이 보이는지`는 사진이 이미 말해요.
   사진 아래에는 왜 멈췄는지, 다음에 무엇을 고를지, 무엇을 포기했는지가 와야 해요.
3. **리듬이 기계적으로 보여요.** 가루이자와는 9장·9문단이 1:1로 너무 반듯하고, 북알프스는
   비슷한 감정 어미가 반복돼요. 세토우치는 일정·감상·모객 문구가 한 문단과 끝부분에 겹쳐요.
4. **독자 조건과 실용 정보가 늦어요.** 6070 독자가 궁금해할 걷는 길이, 환승, 계단, 휴식,
   선택 일정이 장면 뒤에 선명하게 정리되지 않아요. 단, 카페 일정표에 없는 수치나 체험은
   덧붙이지 않아요.
5. **CTA가 감상의 흐름을 끊어요.** 감상 중인 독자에게 갑자기 모객 링크만 내밀지 말고, 실제
   사진·일정의 기준 상세 게시글 한 링크만 마지막에 둬요. 최신 모집·가격 업데이트는 내부 확인용이에요.

## 4. 확정 편집 규칙

### 사진 하단 문구

- 원문 어절 수 `N`의 목표는 `ceil(N × 0.67)`이에요. 65~70% 범위에서 자연스러운 문장을 우선해요.
- 한 사진에는 `장면 명사 1개 + 사진에 안 보이는 사실/판단 1개 + 사람의 반응 1개`만 남겨요.
- 문장은 기본 1~2개, 서술어는 최대 2개로 제한해요. 연결 사진은 한 문장도 괜찮아요.
- `사진 속`, `한 화면에`, `보여요`, `느껴져요`, `이어져요`를 습관적으로 반복하지 않아요.
- 이미 보이는 색·모양·사물 목록, 일반 관광지 정의, 같은 일정의 재반복을 먼저 삭제해요.
- 시간·요금·예약·경사·계단·화장실·휴식·우천 대안은 사진 문장에 억지로 넣지 말고 별도 정보 블록에 보존해요.
- 세 장이 연속될 때 하나는 감정, 둘은 이동·판단·맥락을 맡겨요.
- `다른 장소로 바꿔도 성립하는가?`라는 사람 검사를 통과하지 못하면 고유 지명·행동·선택을 넣어 다시 써요.

### 본문·SEO

- 제목은 `일본 지역 + 기간/계절/숫자 + 독자 조건 또는 제약 + 구체적 보상` 중 세 요소 이상으로 만들어요.
- 첫 5문장 안에 독자 문제, 실제 확인된 장면, 선택 기준, 읽고 얻을 결과를 넣어요.
- 정보와 감정을 `장면 → 사실 하나 → 작성자의 판단 → 다음 장면`으로 교차해요.
- 고유 지명·역·미술관·식당명은 검색을 위해 남기되 키워드 목록처럼 나열하지 않아요.
- 장소별로 `추천 대상 / 비추천 대상 또는 어려운 점 / 다시 고른다면 바꿀 점` 중 하나를 넣어요.
- 검색 노출·조회수·발행 성공은 서로 다른 지표로 기록해요. 노출을 보장한다고 쓰지 않아요.

### 카페 실제 여행·사진·상품

- 소재는 카페에 실제로 남은 여행글·사진·일정표에서만 고르고, 사진과 기준 상세 게시글 URL을 내부에 고정해요.
- 회사 자산으로 승인된 카페 첨부사진은 `company-owned-approved`로 기록하고, 공개 본문에는 권리·작성 방식 해설을 넣지 않아요.
- 일정이 예정된 글은 `예정이에요`, `고를 수 있어요`로 쓰고, 다녀온 후기처럼 바꾸지 않아요.
- 카페 상세 사진·일정의 기준 게시글을 공개 CTA로 사용하고, 최신 모집 업데이트는 내부 확인용으로만 남겨요.
- 본문에는 `작성자가 새로 다녀온 후기가 아니라`, `실제 여행 장면을 다시 엮은 기록`, `메모가 남아 있어요` 같은 메타 문장을 넣지 않아요.

### 자동 발행

- 매일 09:30 KST에 큐를 확인하되, 24시간에 승인 글 최대 1편만 공개해요.
- 큐에 넣을 조건은 `Sol high PASS + Terra high PASS + Luna high PASS + 카페 원문·일정·사진 고정 + 권리 PASS + 사실 PASS + 중복 PASS + 해요체 + image → text DOM PASS`예요.
- 로그인 만료, 2차 인증, CAPTCHA, 편집기 구조 변경, 공개 검증 실패, 중복 멱등키가 하나라도 있으면 그날은 발행하지 않고 실패 로그만 남겨요.
- 발행 직후 공개 비로그인 화면에서 제목·사진/글 순서·사진 수·금지 문장·CTA를 확인하고, 24~48시간 뒤 검색 발견 여부를 별도로 확인해요.
